# 🔥 Fire v1.0.0

**The first stable release of Fire**, a fast, offline notes app for Windows with tasks, goals and reminders.
No account. No cloud. Everything stays on your PC.

## ✨ Highlights

- 📝 Rich text notes with resizable pictures
- ✅ Tasks with deadlines inside every note
- 🎯 Goals with a progress slider
- ⏰ Real desktop reminders
- 🗂️ Notebooks, labels, pin, star and archive
- 🎨 Light, Dark or System theme with any color
- 🔔 Tray icon and optional Start with Windows
- 🔒 Read-only by default, so nothing changes by accident
- 📦 Import and export notes (`.fire`) and full backups (`.firedata`)
- 🗑️ Trash instead of permanent delete

## ⬇️ Downloads

| Your PC | File |
|---|---|
| 64-bit Intel/AMD (pick this if unsure) | `Fire-x64.exe` |
| 32-bit Intel/AMD (old PCs) | `Fire-x86.exe` |
| 64-bit ARM (Snapdragon, Surface Pro X) | `Fire-arm64.exe` |

Requires **Windows 10 or newer**.

## 📌 Notes

- Your notes live in `Documents\Fire` as plain `.fire` (JSON) files.
- If Windows SmartScreen appears, click **More info**, then **Run anyway**.
- Found a bug or have an idea? [Open an issue](https://github.com/HafizIbrahimSuriya/Fire-NoteMaker/issues).
