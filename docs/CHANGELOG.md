# Changelog

All notable changes to Fire are listed here.

## [1.0.0] - 2026-10-25

First stable release.

### Added
- Rich text notes with pictures you can resize, move and wrap text around
- Tasks inside every note, each with its own deadline
- Goals with a progress slider
- Desktop reminders
- Notebooks, labels, pin, star and archive
- Custom note icons and colors
- Light, Dark and System theme with a custom theme color
- Tray icon and optional Start with Windows
- Read-only notes by default (Edit / Save)
- Search across all notes
- Import and export: single notes (`.fire`) and full backups (`.firedata`)
- Trash folder for deleted notes
- About and Social tabs in Settings
- Windows builds for x64, x86 and ARM64
